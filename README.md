# The Pabna Haunting - Full Stack Edition (light theme)
Frontend: HTML/CSS/JS in public/. Backend: server.js (Node 18+, no npm install needed).
Run:  node server.js   then open http://localhost:3000
Server-side: passcode check, cipher check, CCTV clues, authoritative countdown/penalties/bonus, final answer check, leaderboard (data/leaderboard.json).
API: POST /api/login | GET /api/cam?i= | POST /api/cipher | POST /api/wires | GET /api/start | POST /api/escape | POST /api/score | GET /api/leaderboard
Deploy: Render / Railway / any Node host. Build: none. Start command: node server.js. Env: PORT (auto).
